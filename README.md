## Menjalankan secara lokal

```
pip install -r requirements.txt
streamlit run app.py
```

## Struktur berkas

```
app.py             aplikasi utama
requirements.txt   daftar pustaka yang dibutuhkan
data/              berkas CSV data contoh (opsional)
```
